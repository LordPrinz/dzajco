# Roadmap

Source for `scripts/gh/create-issues.ts`. One row per task. Phase 1 issues already exist (numbers in the ID
column). From phase 2 the script creates the issues at the start of each phase.

Type is the commit and PR type. T9.0 is a spike: its commit type is `chore(infra)` and its issue gets the label `type:spike`. Scope/Area is the commit scope; scope `ci` and `deps` map to area `infra`, and scope `docs` maps to area `docs`. T17 (type `test`) has scope `web`.

Columns: Priority P0 blocks others, P1 this sprint, P2 nice to have. Size S is up to half a day, M is 1 to 2
days. Acceptance criteria are separated by semicolons.
